File formats

One Excel workbook can hold several of these: drop it on any box and each sheet is matched to the kind of data it looks like, for you to confirm. Column names don't have to match: each upload opens a matching step that recognises common labels, can ask Claude about the rest, and remembers what you confirm. A workspace file saves everything you have loaded so you can pick it up later. Headers are case-insensitive. Set the unit your files use under Settings (full amounts, thousands or millions); the app picks millions, thousands or full figures for display from the size of the funds. Add a currency column (ISO code, e.g. EUR) to the cash flows; investment amounts are read in their fund's currency. Contributions negative, distributions positive, NAV is the reported value at a date (the latest NAV per fund is used).

cash_flows:  fund, vintage, fund_size, date, type (Contribution|Distribution|NAV), amount, currency
investments: company, fund, sector, stage (Seed|Series A|...), entry_date, exit_date,
             exit_type (IPO|M&A|Shut down), invested (all cheques), initial_investment,
             realized, unrealized, entry_post_money, latest_post_money, latest_round,
             ownership_entry, ownership_current, founded, pre_investment,
             milestones ("2019-06: text | 2021-03: text"), deal_lead, board_seat (Yes|No)
history:     company, date, round (blank on report rows), post_money, amount_raised,
             fund_invested, ownership, cash_on_hand, monthly_burn,
             revenue (for the quarter), gross_profit, or gross_margin (0.62 or 62%),
             net_income (for the quarter), or profit_margin
team:        name, title, level (optional), joined, focus, prior, education, boards
             one row per person at the firm; background fields are only needed for partners
benchmarks:  vintage, metric (TVPI|IRR|DPI), top, median, bottom
