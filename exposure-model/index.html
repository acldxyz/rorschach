File formats

One Excel workbook can hold both: drop it on either box and each sheet is matched to the kind of data it looks like, for you to confirm. Common alternative column names are recognised (for example "Fair Value", "FMV" or "Carrying Value" for fair_value). Ownership may be given as 0.052 or 5.2%. A position needs either shares plus the company's fully diluted share count, or an ownership figure. A workspace file saves everything you have loaded, with your settings and exit assumptions, so you can pick it up later.

commitments: manager, fund, vintage, fund_size, commitment, carry (0.20 or 20%), currency
             or lp_share (your share of the fund) instead of fund_size and commitment
holdings:    manager, fund, company, sector, security (e.g. Series B Preferred), round,
             investment_date, shares, cost, price_paid (per share), fair_value,
             mark_per_share, as_of, company_fd_shares, ownership (fully diluted)
             required: fund, company, cost, fair_value, and shares + company_fd_shares
             or ownership

Returns

Exit values assume every class converts to common, which holds for most 3x+ outcomes; below that, liquidation preferences change who gets what. Net of carry takes each fund's carry off each position's gain, a deal-by-deal estimate that ignores fees and whole-fund netting.
