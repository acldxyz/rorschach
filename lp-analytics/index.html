Venture Track Record

Load a venture GP's fund cash flows and portfolio company data to see net performance, return concentration, follow-on discipline and company progress.

Data

File formats

Headers are case-insensitive. Set the unit your files use above (full amounts, thousands or millions); the app picks millions, thousands or full figures for display from the size of the funds. Add a currency column (ISO code, e.g. EUR) to the cash flows; investment amounts are read in their fund's currency. Contributions negative, distributions positive, NAV is the reported value at a date (the latest NAV per fund is used).

cash_flows:  fund, vintage, fund_size, date, type (Contribution|Distribution|NAV), amount, currency
investments: company, fund, sector, stage (Seed|Series A|...), entry_date, exit_date,
             exit_type (IPO|M&A|Shut down), invested (all cheques), initial_investment,
             realized, unrealized, entry_post_money, latest_post_money, latest_round,
             ownership_entry, ownership_current, founded, pre_investment,
             milestones ("2019-06: text | 2021-03: text"), deal_lead, board_seat (Yes|No)
history:     company, date, round (blank on report rows), post_money, amount_raised,
             fund_invested, ownership, cash_on_hand, monthly_burn,
             revenue (for the quarter), gross_profit, or gross_margin (0.62 or 62%)
team:        name, title, level (optional), joined, focus, prior, education, boards
             one row per person at the firm; background fields are only needed for partners
benchmarks:  vintage, metric (TVPI|IRR|DPI), top, median, bottom
